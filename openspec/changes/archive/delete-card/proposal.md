## Why

На текущий момент пользователь не может удалить карточку с доски — ни ошибочно созданную, ни просто ненужную. Однажды добавленная карточка остаётся навсегда. Это ограничивает управление списком задач и создаёт шум в интерфейсе. Функция удаления необходима для полноценного контроля над содержимым доски.

## What Changes

- Пользователь получает возможность удалить любую карточку через кнопку в интерфейсе `BoardCard`.
- После подтверждения удаления карточка отправляет `DELETE /cards/:id` на сервер.
- После успешного удаления TanStack Query инвалидирует кэш `["cards"]`, и карточка исчезает из UI без перезагрузки страницы.
- Обработка ошибок (сетевые сбои, 4xx/5xx) — отображение уведомления об ошибке.

## Capabilities

### New Capabilities

- `card-deletion`: Возможность удаления карточки с доски через UI с отправкой DELETE-запроса на сервер и автоматическим обновлением списка через TanStack Query.

## Impact

- **Клиент — API:** `client/src/api/cards.ts` — добавить функцию `deleteCard(id: string)`.
- **Клиент — UI:** `client/src/components/BoardCard/BoardCard.tsx` — добавить кнопку удаления и обработчик `onDelete`.
- **Клиент — UI:** `client/src/components/BoardColumn/BoardColumn.tsx` — пробросить `id` и `onDelete` в `BoardCard`.
- **Клиент — типы:** `client/src/types/card.ts` — изменения не требуются (`id: string` уже есть).
- **Клиент — стейт:** `client/src/App.tsx` — изменения не требуются (React Query инвалидирует кэш автоматически).
- **Сервер (mock):** json-server уже поддерживает `DELETE /cards/:id` из коробки — изменений не требуется.
- **Сервер (реальный):** `server/` — пустая директория; реализация `DELETE /cards/:id` потребуется при переходе на Express (тема 3 курса).
