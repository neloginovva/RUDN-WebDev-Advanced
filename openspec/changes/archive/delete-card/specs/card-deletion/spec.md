## Purpose

Позволяет пользователю удалять ненужные или ошибочно созданные карточки с доски через интерфейс, с автоматическим обновлением списка и уведомлением об ошибках.

## ADDED Requirements

### Requirement: User can initiate card deletion

На доске каждая карточка содержит видимый элемент интерфейса (кнопку удаления), позволяющий пользователю запустить процесс удаления этой карточки.

#### Scenario: User initiates deletion via delete button

- **WHEN** пользователь видит карточку на доске и нажимает кнопку удаления на этой карточке
- **THEN** система отображает диалог подтверждения удаления с названием карточки

#### Scenario: Delete button is visible for every card

- **WHEN** пользователь открывает доску
- **THEN** каждая карточка отображается с кнопкой удаления

### Requirement: Deletion confirmation dialog

Перед фактическим удалением система запрашивает подтверждение у пользователя.

#### Scenario: User confirms deletion

- **WHEN** пользователь нажимает кнопку подтверждения в диалоге подтверждения удаления
- **THEN** система отправляет запрос на удаление карточки на сервер и закрывает диалог

#### Scenario: User cancels deletion

- **WHEN** пользователь отменяет подтверждение удаления (нажимает «Отмена» или закрывает диалог)
- **THEN** диалог закрывается, карточка остаётся на доске без изменений

### Requirement: Card is removed from the board after successful deletion

После успешного удаления карточки сервером, карточка исчезает из интерфейса доски.

#### Scenario: Card disappears from board after successful deletion

- **WHEN** сервер подтверждает удаление карточки
- **THEN** карточка немедленно исчезает из списка на доске без перезагрузки страницы

#### Scenario: Board re-renders after deletion

- **WHEN** удаление завершено успешно
- **THEN** система обновляет состояние доски и перерисовывает список оставшихся карточек

### Requirement: Error handling for failed deletion

Если удаление не удалось, пользователь получает уведомление об ошибке, а карточка остаётся на доске.

#### Scenario: Network error during deletion

- **WHEN** при отправке запроса на удаление возникает сетевая ошибка
- **THEN** система отображает уведомление об ошибке, а карточка остаётся на доске

#### Scenario: Server error during deletion

- **WHEN** сервер возвращает ошибку (статус 4xx или 5xx) при удалении карточки
- **THEN** система отображает уведомление об ошибке, а карточка остаётся на доске

### Requirement: Deleted card remains deleted after page reload

Данные о карточке хранятся на сервере, поэтому после перезагрузки страницы удалённая карточка не появляется.

#### Scenario: Deleted card does not return after page reload

- **WHEN** пользователь удаляет карточку, а затем перезагружает страницу
- **THEN** удалённая карточка не отображается на доске
