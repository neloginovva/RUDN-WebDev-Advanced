# Proposal: cards-counter

## Why

Пользователь видит название доски «Канбан-доска», но не может быстро оценить, сколько карточек на ней находится. При большом количестве задач приходится прокручивать колонку и считать вручную — это раздражает и замедляет обзор.

## What Changes

- Рядом с названием доски в компоненте `BoardHeader` отображается количество карточек, загруженных с сервера.
- Пример отображения: `Канбан-доска · 3` (число обновляется при каждом рефетче данных).
- Если карточки ещё загружаются — показывается индикатор загрузки (спиннер или текст «…»).
- Если карточек нет — отображается `0`.

Поведение пользователя: никаких новых действий не требуется. Пользователь просто видит актуальное число рядом с заголовком доски при каждом открытии страницы.

## Capabilities

- **Board Header** — расширение компонента `BoardHeader` для отображения метаданных доски (количества карточек).
- **Cards List** — использование уже существующего запроса TanStack Query (`useQuery({ queryKey: ["cards"] })`) для получения списка карточек в компоненте заголовка.

## Impact

| Часть проекта | Что затрагивается |
|---|---|
| `client/src/components/BoardHeader/BoardHeader.tsx` | Компонент получит данные о карточках (через TanStack Query) и будет рендерить счётчик рядом с заголовком. |
| `client/src/components/BoardHeader/BoardHeader.module.css` | Возможно добавление стилей для контейнера счётчика (отступ, цвет, размер шрифта). |
| `client/src/App.tsx` | `BoardHeader` сейчас рендерится без пропсов; при необходимости можно передать `queryClient` или оставить запрос внутри хедера. |
| `client/db.json` | Без изменений — счётчик читает данные, не модифицирует их. |
| `server/` | Без изменений — данные берутся из существующего эндпоинта `GET /api/cards`. |

Изменения минимальны и локализованы в компоненте `BoardHeader`. Новая зависимость от TanStack Query уже присутствует в проекте (используется в `App.tsx` и `NewCardForm`).
