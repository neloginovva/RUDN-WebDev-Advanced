## Purpose

Отображение количества карточек на канбан-доске в заголовке доски для быстрого обзора без необходимости прокрутки и ручного подсчёта.

## ADDED Requirements

### Requirement: Счётчик показывает общее количество карточек на доске

Система SHALL отображать рядом с названием доски общее количество карточек, загруженных с сервера, включая как выполненные, так и невыполненные карточки.

> **Решение по конфликту:** Счётчик показывает ВСЕ карточки, включая выполненные (`isDone` не влияет на подсчёт). Это следует из формулировки в proposal: «количество карточек, загруженных с сервера». Пользователь открывает доску, чтобы увидеть полную картину — а не только незавершённые задачи. Фильтрация по статусу — отдельная функция, а не часть счётчика.

#### Scenario: Счётчик на доске с карточками

- **WHEN** пользователь открывает канбан-доску, содержащую карточки
- **THEN** в заголовке доски отображается актуальное число карточек (например, «Канбан-доска · 3»)

#### Scenario: Счётчик на пустой доске

- **WHEN** пользователь открывает канбан-доску, не содержащую карточек
- **THEN** в заголовке доски отображается `0`

#### Scenario: Счётчик при загрузке данных

- **WHEN** пользователь открывает доску и карточки ещё загружаются с сервера
- **THEN** в заголовке доски отображается индикатор загрузки (спиннер или текст «…») вместо числа

#### Scenario: Счётчик с выполненными карточками

- **WHEN** пользователь открывает доску, содержащую как выполненные, так и невыполненные карточки
- **THEN** в заголовке отображается суммарное количество всех карточек (выполненные + невыполненные), а не только невыполненных

#### Scenario: Обновление счётчика при изменении данных

- **WHEN** пользователь добавляет, перемещает или удаляет карточку на доске
- **THEN** счётчик в заголовке обновляется до нового актуального значения
