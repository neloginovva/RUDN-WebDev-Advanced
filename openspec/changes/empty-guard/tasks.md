# Tasks: empty-guard

## 1. Расширить атрибут `disabled` кнопки

**Файлы:** `client/src/components/NewCardForm/NewCardForm.tsx` (строка 42)

### 1.1 Добавить условие `!title.trim()` в `disabled`

**Действие:**
Заменить строку 42 в `NewCardForm.tsx`:

```tsx
// Было:
disabled={mutation.isPending}

// Стало:
disabled={!title.trim() || mutation.isPending}
```

**Результат:**
- Кнопка получает атрибут `disabled` при пустом или пробельном вводе.
- CSS-селектор `.button:disabled` из `NewCardForm.module.css` (строки 38–40) автоматически применяет `opacity: 0.5` и `cursor: not-allowed`.

**Проверка:**
- В DevTools элемент `<button>` имеет атрибут `disabled` когда поле пустое.
- Визуально кнопка полупрозрачна и не меняет яркость при `:hover`.

## 2. Проверка: блокировка создания карточки

### 2.1 Пустое поле

**Условия:** Поле ввода пустое (`title === ""`).

**Действие:** Нажать кнопку «Добавить».

**Ожидаемый результат:**
- Карточка не отправляется на сервер (нет `POST /api/cards`).
- Поле ввода остаётся пустым и доступным для ввода.
- Кнопка заблокирована (`disabled`).

### 2.2 Поле из одних пробелов

**Условия:** Поле ввода содержит только пробелы (`title === "   "`).

**Действие:** Нажать кнопку «Добавить».

**Ожидаемый результат:**
- Карточка не отправляется на сервер.
- Поле ввода остаётся без изменений.
- Кнопка заблокирована (`disabled`).

## 3. Проверка: сохранение прежнего поведения

### 3.1 Непустое название

**Условия:** Поле ввода содержит текст с хотя бы одним непробельным символом.

**Действие:** Нажать кнопку «Добавить».

**Ожидаемый результат:**
- Отправляется `POST /api/cards` с телом `{ title: "...", isDone: false, isUrgent: false }`.
- Карточка появляется на доске после ответа сервера.
- Поле ввода очищается (`setTitle("")`).
- Кнопка разблокирована (`disabled` отсутствует).

### 3.2 Состояние во время загрузки

**Условия:** Карточка с непустым названием отправляется на сервер.

**Действие:** Дождаться ответа сервера.

**Ожидаемый результат:**
- Кнопка заблокирована (`disabled`) и показывает текст "Добавление...".
- После успешного ответа — разблокируется, текст вернётся к "Добавить".

## 4. Проверка: визуальное неактивное состояние кнопки

### 4.1 Пустое поле при открытии доски

**Условия:** Страница загружена, поле ввода пустое.

**Ожидаемый результат:**
- Кнопка «Добавить» имеет `opacity: 0.5` и `cursor: not-allowed`.
- Кнопка не реагирует на `:hover` (без `filter: brightness(1.1)`).
- При навигации через `Tab` кнопка пропускается (атрибут `disabled` блокирует фокус).

### 4.2 Заполнение поля

**Условия:** Пользователь вводит текст в пустое поле.

**Ожидаемый результат:**
- Как только поле содержит хотя бы один непробельный символ, кнопка разблокируется.
- Кнопка получает стандартный стиль: `opacity: 1`, `cursor: pointer`, реагирует на `:hover`.

### 4.3 Очистка поля после создания карточки

**Условия:** Карточка успешно создана, поле очищено через `setTitle("")`.

**Ожидаемый результат:**
- Кнопка снова блокируется и выглядит неактивно.
